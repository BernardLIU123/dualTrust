## 1. 策略概述

本策略是基于 Dual Thrust 思想的分钟级日内开盘区间突破（Opening Range Breakout，ORB）策略，运行于上海期货交易所（SHFE）天然橡胶（RU）期货的 1 分钟 K 线（bar）上。

- **适用品种**：上期所天然橡胶 RU。
- **K 线周期**：1 分钟 bar。
- **交易时段**：以夜盘 21:00 开盘作为当日起点（与交易所日线口径一致）。开盘后前 15 分钟（21:00–21:15，含首尾，共 15 根 1 分钟 bar）为观察期，只收集区间、不交易；21:15 起轨道激活，进入交易时段。
- **策略类型**：日内开盘区间突破。以开盘 15 分钟区间计算上下轨道，1 分钟 bar 收盘价突破轨道即入场；**14:55 市价强平，绝不隔夜**（规避夜盘跳空与隔夜保证金风险）。
- **仓位管理**：固定手数（默认 1 手）。
- **系统定位**：完整实盘方案——策略逻辑 + 实盘交易架构（CTP 接口、风控、监控、容灾），回测与实盘使用同一份策略代码。

一句话概括：**开盘 15 分钟定区间，突破放大轨道入场，ATR 与区间双保险止损，14:55 强平不隔夜。**

## 2. 市场逻辑与适用性

### 2.1 为什么是橡胶

- **国际联动**：沪胶是全球天然橡胶定价中心之一，与新加坡 SICOM、日本 TOCOM 及东南亚主产区现货市场联动密切。夜盘时段（21:00–23:00）与产区现货交易活跃时间重叠，海外信息（天气、产量、库存、政策）传导快，价格容易形成单边行情——这正是突破策略盈利的前提。
- **夜盘流动性**：RU 夜盘 21:00 开盘即全天交易起点，开盘后的 15 分钟内成交量与波动集中，价格充分消化隔夜信息，适合收集有代表性的开盘区间，也保证了突破信号出现后的成交质量。
- **日内波动性**：橡胶日内振幅较大，为突破入场后的趋势行情提供足够的盈利空间；同时"14:55 强平、不隔夜"的设计使策略不承担隔夜跳空风险。

### 2.2 适用与不适用的行情

- **适用——趋势日**：开盘后价格沿单一方向持续运行，突破轨道后趋势延续，策略吃到主要波段。
- **不适用——窄幅震荡日**：价格在区间附近反复穿越轨道，频繁触发假突破，止损连续被扫。单日亏损由"每方向每日最多一次"与止损规则封顶，但连续震荡日会累积亏损。

因此回测必须覆盖 ≥ 3 年的完整周期（含趋势市与震荡市），并以样本外验证确认策略在两类行情下的整体表现（见第 8 章）。

## 3. 算法原理与公式

### 3.1 开盘区间（Range）

以交易日 D 的 21:00–21:15（含首尾）共 15 根 1 分钟 bar 计算：

```
RangeHigh = max(区间内 high)      RangeLow = min(区间内 low)
Range     = RangeHigh - RangeLow
```

- 21:00–21:15 为**观察期**（状态 `COLLECTING`），区间未定前无轨道、不交易；
- 21:15 起轨道激活（状态 `ARMED`），开始监控突破；
- 区间一天只计算一次，全天固定不变。

### 3.2 轨道公式

```
上轨 Upper = RangeHigh + K1 × Range
下轨 Lower = RangeLow  - K2 × Range
```

其中 K1 为上轨放大系数，K2 为下轨放大系数（默认均为 0.5）。

### 3.3 轨道结构图示

```
价格
  ▲
  │ ══════════════════════════════════════════════  上轨 Upper = RangeHigh + K1 × Range
  │            ▲
  │            │ K1 × Range（向上放大）
  │ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  区间高点 RangeHigh = max(high)
  │            │
  │            │   Range = RangeHigh - RangeLow（开盘 15 分钟区间，全天固定）
  │            │
  │ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  区间低点 RangeLow  = min(low)
  │            ▼
  │            │ K2 × Range（向下放大）
  │ ══════════════════════════════════════════════  下轨 Lower = RangeLow - K2 × Range
  │
  └── 21:00 ────────────── 21:15 ──────────── … ──────────────── 14:55 ──► 时间
      COLLECTING              ARMED                                   CLOSED
      （只观察，不交易）        （轨道激活，收盘价突破即开仓）            （强平离场）
```

### 3.4 K1 与 K2 的含义

- **K1（上轨系数）**决定做多门槛：K1 越大，上轨离区间高点越远，做多信号越"严格"、越滞后；
- **K2（下轨系数）**决定做空门槛：K2 越大，下轨离区间低点越远，做空信号越"严格"、越滞后；
- K1 / K2 允许不对称设置（例如根据品种多空波动差异分别调优），默认 0.5 / 0.5，优化范围 0.2–0.9，步长 0.1。

"锚定 + 放大"是 Dual Thrust 的核心思想：以开盘 15 分钟的价格行为为锚，将区间放大后形成突破轨道，过滤区间内的噪音波动。

## 4. 交易规则

### 4.1 日内状态机

RU 交易日跨夜（21:00 → 次日 15:00），策略实现严格的日内状态机（state machine）：

| 状态 | 触发条件 | 行为 |
|------|---------|------|
| `COLLECTING` | 21:00 开盘 | 收集前 15 根 1 分钟 bar，只观察不交易 |
| `ARMED` | 21:15（区间确定） | 计算上下轨，激活突破监控；ATR 开始累积 |
| `LONG` / `SHORT` | 突破触发 | 持有多/空，跟踪止损线 |
| `STOPPED` | 止损或反手 | 当日不再同向开仓 |
| `CLOSED` | 14:55 强平 | 平仓，等待下一交易日 21:00 重置 |

- **交易日切换检测**：用 `on_bar` 的 datetime 判断，进入新交易时段 21:00 时重置全部日内状态、重算轨道；
- **实盘 tick → 1 分钟 bar**：CTP tick 经 `BarGenerator` 合成，与回测 bar 口径完全一致；
- **回放一致性**：回测引擎按序回放 bar，21:00–21:14 的 bar 走 `COLLECTING`，与实盘路径相同——同一状态机、同一份代码，保证回测与实盘无逻辑漂移。

### 4.2 规则明细

每条规则按"触发条件 / 动作 / 理由"展开。

**规则 1：观察期（不交易）**

- 触发条件：新交易日 21:00 开盘。
- 动作：状态进入 `COLLECTING`，收集前 15 根 1 分钟 bar 的高低点；此期间无轨道，不发任何委托。
- 理由：区间未定前无入场依据，避免凭主观猜测交易。

**规则 2：区间计算与轨道激活**

- 触发条件：21:15，15 根 bar 收集完毕。
- 动作：按 3.1 / 3.2 公式计算 RangeHigh、RangeLow、Range、Upper、Lower，状态进入 `ARMED`；轨道全天固定不变，ATR 开始累积。
- 理由：以开盘 15 分钟价格行为锚定当日波动基准，再经 K1 / K2 放大过滤区间内噪音。

**规则 3：突破开仓**

- 触发条件：状态 `ARMED` 下，某根 1 分钟 bar 收盘价 `close > Upper`（向上突破）或 `close < Lower`（向下跌破），且该方向当日尚未交易过。
- 动作：向上突破 → 开多 `fixed_size` 手；向下跌破 → 开空 `fixed_size` 手；开仓同时按规则 6 设定初始止损线。
- 理由：以 bar 收盘价判定突破，避免盘中瞬时毛刺触发假信号；收盘突破是趋势启动的经典确认。

**规则 4：每方向每日最多一次**

- 触发条件：某方向当日已开仓过一次（无论当前是否仍持仓、是否已止损/反手）。
- 动作：该方向当日不再开新仓。两个方向各限一次，因此当日最多两次方向性开仓（各方向一次）。
- 理由：限制单日交易频率与单日亏损上限，是策略内第一层风控。

**规则 5：反手（reverse）**

- 触发条件：当日两个方向先后被触发（例如先开多，随后价格向下跌破 Lower）。
- 动作：市价平掉原持仓，按 `fixed_size` 反向开仓（先开的一方平仓转另一方）。
- 理由：价格向反方向突破说明原方向判断失效，顺势切换；反手方向同样占用其"每日一次"额度。

**规则 6：止损（stop loss）**

- 触发条件：持仓期间价格触及初始止损线。
- 动作：市价平仓，状态进入 `STOPPED`，当日不再开新仓。
- 公式：

```
stop_distance = max(ATR(30) × stop_atr_mult, 0.5 × Range)
多单止损线 = 开仓价 - stop_distance
空单止损线 = 开仓价 + stop_distance
```

其中 ATR（Average True Range，平均真实波幅）基于 1 分钟 bar 计算，周期 30（vn.py ArrayManager）；`stop_atr_mult` 默认 2.0。
- 理由：`0.5 × Range` 下界保证止损距离不小于半个开盘区间，避免波动率极低时止损过紧被噪音扫损；ATR 项让止损随近期波动率自适应；两者取大，构成双重保护。

**规则 7：14:55 强制平仓（force close）**

- 触发条件：14:55 仍持有仓位。
- 动作：市价平仓，状态进入 `CLOSED`，当日不再交易，等待下一交易日 21:00 重置。
- 理由：绝不隔夜——规避夜盘跳空与隔夜保证金风险，是日内策略的持仓周期边界。

**开盘价定义**：以夜盘 21:00 开盘作为当日起点，区间在 21:00–21:15 收集（与交易所日线口径一致）。

## 5. 参数说明

### 5.1 参数表（默认值与优化范围）

| 参数 | 含义 | 默认 | 优化范围 |
|------|------|------|---------|
| `window_minutes` | 开盘区间分钟数 | 15 | 10 / 15 / 30 |
| `k1` | 上轨系数 | 0.5 | 0.2–0.9，步长 0.1 |
| `k2` | 下轨系数 | 0.5 | 0.2–0.9，步长 0.1 |
| `atr_length` | ATR 周期（1 分钟 bar） | 30 | 20–60 |
| `stop_atr_mult` | 止损 ATR 倍数 | 2.0 | 1.5–2.5 |
| `fixed_size` | 固定手数 | 1 | 1–5 |
| `force_close_time` | 强平时间 | 14:55 | 14:50–14:59 |

### 5.2 各参数的调整效果

- **`window_minutes`**：调大（如 30）→ 区间更宽更稳定，轨道更宽，信号更少、更滞后，趋势过滤更强；调小（如 10）→ 区间更敏感，信号更早，但噪音更多。该参数优化时取离散值（10 / 15 / 30）。
- **`k1` / `k2`**：调大 → 轨道距区间越远，突破越难触发，假突破过滤更强，但入场更晚、单笔盈利空间被压缩；调小 → 越容易触发，信号更多，假突破风险上升。k1 只影响上轨（做多门槛），k2 只影响下轨（做空门槛），两者可独立调整。
- **`atr_length`**：调大 → ATR 更平滑，止损更稳定，但对近期波动率变化反应更慢；调小 → 反应更快，但更易受短期噪音影响。
- **`stop_atr_mult`**：调大 → 止损更宽，容错更高，但单笔最大亏损变大；调小 → 止损更紧，单笔亏损更小，但更易被正常波动扫损（注意 `0.5 × Range` 下界仍生效）。
- **`fixed_size`**：调大 → 盈亏与风险同比例放大，受保证金与账户级风控约束；调小 → 反之。
- **`force_close_time`**：调晚（如 14:59）→ 持仓时间更长，可捕捉尾盘行情，但临近收盘流动性下降、执行风险上升；调早（如 14:50）→ 更保守，提前锁定离场，规避尾盘不确定性。

## 6. 合约特性与实盘参数

### 6.1 合约规格

- 合约单位：10 吨/手。
- 最小变动价位：5 元/吨（= 50 元/手，即 1 tick 价值 50 元/手）。

### 6.2 交易时段

| 时段 | 时间 | 说明 |
|------|------|------|
| 夜盘 | 21:00–23:00 | 策略观察期（21:00–21:15）与夜盘交易均在此 |
| 日盘上午 | 9:00–10:15 / 10:30–11:30 | 正常监控突破与持仓 |
| 日盘下午 | 13:30–15:00 | 14:55 强平在此时段 |

- 集合竞价时段（20:55–21:00）不发单（容灾设计的一部分，见 9.5）。

### 6.3 费用与保证金

- 手续费：默认 3 元/手双边（上期所标准，以交易所最新公告为准，配置项可改）。
- 保证金率：默认 10%（交易所约 7% + 期货公司上浮，配置项可改）；按现价折算，1 手 RU 保证金约 1.7 万元。

### 6.4 涨跌停保护

临近涨跌停价位不追单、不开仓——避免在极端行情下于无法成交或即将反向的价位入场。

### 6.5 主力合约换月

- 回测：使用主力连续序列，前复权消除换月跳空；
- 实盘：在交割月前切换至新主力合约，避免交割月流动性下降与交割风险。

## 7. 风险控制

三层风控体系（与设计文档 5.1 一致）：

### 7.1 第一层：策略内（代码级）

- 止损：`max(ATR(30) × 2, 0.5 × Range)`（即 `stop_atr_mult` = 2.0），市价平仓，当日不再开仓；
- 每方向每日最多一次；
- 14:55 强平，绝不隔夜；
- 涨跌停保护：临近涨跌停不追单、不开仓；
- 单策略最大持仓 = `fixed_size`。

### 7.2 第二层：RiskManager 模块（引擎级，vn.py 自带）

- 流控：每秒/每分钟最大委托笔数；
- 单笔最大手数、当日总委托手数上限；
- 活动委托数上限（防重复发单）；
- 下单前保证金充足性检查。

### 7.3 第三层：账户级（盘前人工复核）

- 每日最大亏损熔断：默认日亏超权益 2% → 当日停策略；
- 账户级最大回撤线：默认 20% → 全面停策略并复盘。

## 8. 回测方法与绩效评估

### 8.1 回测设置

| 项目 | 设定 |
|------|------|
| 引擎 | vn.py CtaBacktester（与实盘同一策略代码） |
| 数据 | 自供 1 分钟数据，主力连续序列（换月跳空前复权） |
| 回测区间 | ≥ 3 年（覆盖趋势市 + 震荡市完整周期） |
| 手续费 | 3 元/手双边（可配置） |
| 滑点 | 默认 1 tick（50 元/手）；另跑 0 / 2 tick 敏感性 |
| 保证金率 | 10% |
| 起始资金 | 10 万（1 手 RU 保证金约 1.7 万，缓冲充足） |

分钟级数据文件由用户提供，系统定义标准格式与导入模块（见 9.2）。

### 8.2 绩效指标与公式

指标口径从 vn.py CtaBacktester 的 `calculate_statistics` 摘录（年化交易日数按 240 计）：

**收益类**

- 总收益率 = (期末权益 / 起始资金 − 1) × 100%
- 年化收益率 = 总收益率 ÷ 总交易日数 × 240
- 日收益率（对数口径）：r_t = ln(当日权益 / 前一日权益)
- 月度收益分布：按月汇总净盈亏，观察收益的月度分布形态

**风险类**

- 最大回撤（Maximum Drawdown）= max(1 − 权益_t / 历史峰值权益_t) × 100%，即权益相对滚动历史最高值的最大跌幅
- 最大单日亏损 = min(单日净盈亏)
- 年化波动率 = 日收益率标准差 × √240

**风险调整类**

- 夏普比率（Sharpe Ratio）= (日均收益率 − 日化无风险利率) ÷ 日收益率标准差 × √240；其中年化无风险利率 rf = 2.5%，日化无风险利率 = rf ÷ √240
- 卡玛比率（Calmar Ratio）= 年化收益率 ÷ |最大回撤|（vn.py 内置"收益回撤比"以总收益率计，报告按标准卡玛口径以年化收益率计）
- 索提诺比率（Sortino Ratio）= (年化收益率 − rf) ÷ 年化下行标准差；年化下行标准差 = √(mean(min(r_t, 0)²)) × √252（下行偏差口径，与 vn.py 内部下行风险计算一致）

**交易类**

- 交易次数：全部开平仓交易的笔数
- 胜率 = 盈利交易次数 ÷ 总交易次数
- 盈亏比 = 平均单笔盈利金额 ÷ 平均单笔亏损金额（绝对值）
- 平均持仓时长 = 各笔交易 (平仓时间 − 开仓时间) 的平均值
- 日均信号数 = 总信号次数 ÷ 总交易日数

**成本敏感性**

- 成本占比 = (总手续费 + 总滑点) ÷ 毛利润；毛利润 = 总净盈亏 + 总手续费 + 总滑点（即扣费前利润）
- 成本占比 > 30% 视为策略对执行成本过于敏感，需警惕

### 8.3 样本内 / 样本外设计

```
完整区间（3 年+）
├── 样本内（前 70%）：网格搜索参数寻优
└── 样本外（后 30%）：参数固定，一次性验证，结果作废后不再调参
```

样本外结果一旦使用过即"作废"，不得再据其调参——防止过拟合（overfitting）。

### 8.4 验收门槛

以下门槛为 Phase 0 退出条件；任一不达标 → 返回优化，不进入仿真：

| 指标 | 门槛 |
|------|------|
| 夏普比率（样本外） | ≥ 1.0 |
| 最大回撤 | ≤ 20% |
| 样本外夏普 / 样本内夏普 | ≥ 60% |
| 成本占比 | ≤ 30% |
| 分年度正收益年份占比 | ≥ 60% |
| 参数微扰稳定性（±0.1） | 夏普变化 ≤ 25% |

另需满足：

- 分年度绩效表：表现不依赖单一特定行情年份；
- 基准对比：同期买入持有 + 经典日线版 Dual Thrust 对照，证明分钟级改造的增量价值。

## 9. 实盘部署

### 9.1 vn.py 系统架构

```
┌─────────────────────────── 应用层（GUI/脚本） ───────────────────────────┐
│  CtaBacktester（回测+参数优化）   CtaStrategyPro（实盘）  RiskManager（风控）│
├─────────────────────────── 引擎层 ────────────────────────────────────┤
│  CtaEngine：策略调度、bar 推送、发单路由         OmsEngine：委托/成交/持仓 │
│  DataManager：历史数据管理（SQLite 存储）        AlgoTrading：可选 │
├─────────────────────────── 策略层 ────────────────────────────────────┤
│  DualThrustStrategy(CtaTemplate)：算法核心（回测实盘同一份代码）        │
├─────────────────────────── 接口层 ────────────────────────────────────┤
│  CTP Gateway（实盘） / CTP SimNow（仿真先行）                          │
└──────────────────────────────────────────────────────────────────────┘
```

- 回测与实盘运行同一份策略代码（一体化架构，方案 A），杜绝逻辑漂移；
- CTP（Comprehensive Transaction Platform，综合交易平台）Gateway 负责实盘行情与交易；SimNow（上期技术仿真平台）先行仿真验证。

### 9.2 数据管道

```
分钟数据文件(CSV) ──→ tools/import_data.py ──→ vnpy SQLite 数据库 ──→ 回测引擎
```

- 标准文件格式：`datetime, open, high, low, close, volume, open_interest`（UTC+8，`YYYY-MM-DD HH:MM:SS`）；
- 支持单合约（如 ru2601）与主力连续序列；
- 导入脚本校验：时间戳单调、价格合法性（high ≥ low ≥ 0）、缺失 bar 检测、重复行拒绝。

### 9.3 四阶段上线路径

| 阶段 | 内容 | 退出条件 |
|------|------|---------|
| Phase 0 | 回测验证（样本内 + 样本外 + 参数稳定性） | 见 8.4 验收门槛 |
| Phase 1 | SimNow 仿真盘运行 ≥ 1 个月 | 状态机零异常、信号一致率 100%、断线/强平实测通过 |
| Phase 2 | 实盘小资金（1 手）试运行 | 实盘滑点与回测假设偏差 < 1 tick |
| Phase 3 | 逐步加仓至目标手数 | 每阶段观察 ≥ 2 周 |

任一阶段退出条件不满足 → 停留或回退到上一阶段，不进入下一阶段。

### 9.4 监控与告警

事件引擎 → 钉钉/邮件推送：

| 告警项 | 级别 | 动作 |
|--------|------|------|
| 开仓/平仓成交回报 | 信息 | 推送成交详情 |
| 止损触发 | 警告 | 立即推送 |
| 14:50 仍持仓（强平预警） | 警告 | 推送，人工介入确认 |
| 行情中断（连续 5 分钟无 bar） | 严重 | 停止开仓 + 推送 |
| 网关断线/重连 | 严重/信息 | 推送 |
| 委托被拒/废单 | 严重 | 推送 + 停止开仓 |

盘中状态面板：持仓、上下轨位置、当日信号次数、已实现盈亏。

### 9.5 容灾要点

- **断线重连**：CTP Gateway 自动重连；重连成功后校验本地持仓与柜台持仓一致性，不一致 → 告警停机；
- **行情保护**：连续 5 分钟无新 bar → 禁止开仓，持仓进入纯风控模式（止损/强平仍生效）；
- **进程守护**：Windows 任务计划/服务方式启动，崩溃自动拉起，启动时恢复策略状态；
- **审计日志**：完整委托/成交/状态机转换日志，每日归档；
- **交易日历**：节假日/临时休市日历，非交易日跳过；集合竞价时段（20:55–21:00）不发单。

## 10. 边界情形与异常处理

| 情形 | 系统行为 |
|------|---------|
| 区间零宽度（RangeHigh = RangeLow，Range = 0） | 公式自然退化：Upper = Lower = RangeHigh；`0.5 × Range` = 0，止损完全由 `ATR(30) × stop_atr_mult` 决定；突破按收盘价严格大于/小于轨道判定（等于轨道值不视为突破）；该边界由单元测试覆盖 |
| 开盘数据缺失（21:00–21:15 的 bar 不完整） | 状态机保持 `COLLECTING`，收集满 15 根 bar 前无轨道、不交易；若缺失源于行情中断，另触发"连续 5 分钟无 bar"行情保护；回测侧由导入工具的缺失 bar 检测告警，保证回测数据完整 |
| 涨停/跌停封板 | 涨跌停保护：临近涨跌停价位不追单、不开仓；已持仓的止损/强平平仓委托若因封板无法立即成交，保持委托直至成交，并触发"委托被拒/废单"告警（严重级，停止开仓） |
| 行情中断（连续 5 分钟无 bar） | 停止开仓 + 告警推送；已持仓进入纯风控模式，止损与 14:55 强平仍生效 |
| 持仓不一致（断线重连/重启后） | 校验本地持仓与柜台持仓一致性，不一致 → 告警停机，人工按审计日志核对后恢复 |
| 换月跳空 | 回测：主力连续序列 + 前复权消除跳空；实盘：交割月前切换至新主力，新合约自新交易日 21:00 起重新收集区间、重置状态机 |

## 11. 附录

### 11.1 术语表

| 术语 | 英文 | 含义 |
|------|------|------|
| 开盘区间突破 | Opening Range Breakout（ORB） | 以开盘后固定时段的高低点构成区间，突破区间放大后的轨道入场 |
| 开盘区间 | Range | 开盘 15 分钟最高价与最低价之差（RangeHigh − RangeLow） |
| 平均真实波幅 | Average True Range（ATR） | 一段时间内真实波幅的均值，衡量波动率；本策略取 30 个 1 分钟 bar |
| 最小变动价位 | tick | 价格最小变动单位，RU 为 5 元/吨（50 元/手） |
| 主力连续 | — | 各时期主力合约拼接而成的连续价格序列，回测中前复权消除换月跳空 |
| 前复权 | — | 以当前价格为基准调整历史价格，使换月跳空在数据上平滑 |
| 滑点 | slippage | 实盘成交价相对回测假设价的偏差；默认按 1 tick（50 元/手）计 |
| 反手 | reverse | 当日反向信号触发时，平掉原仓位并反向开仓 |
| 强平 | force close | 14:55 无条件市价平仓，保证不隔夜 |
| 市价单 | market order | 以当前市场最优价成交的委托 |
| 保证金 | margin | 持仓所需冻结资金；RU 默认按 10% 计 |
| 涨跌停 | price limit | 交易所规定的单日价格波动上下限 |
| 集合竞价 | call auction | 开盘前的集中撮合时段（RU 夜盘 20:55–21:00），此期间不发单 |
| CTP | Comprehensive Transaction Platform | 国内期货综合交易平台接口，实盘经 CTP Gateway 接入 |
| SimNow | — | 上期技术仿真交易平台，用于上线前仿真验证（Phase 1） |
| 状态机 | state machine | 策略日内状态流转模型（COLLECTING / ARMED / LONG / SHORT / STOPPED / CLOSED） |
| BarGenerator | — | vn.py 中将 tick 合成为 1 分钟 bar 的组件 |
| ArrayManager | — | vn.py 中维护 K 线数组并计算 ATR 等指标的组件 |
| 网格搜索 | grid search | 在参数优化范围内按步长枚举组合，寻找样本内最优参数 |
| 样本内 / 样本外 | in-sample / out-of-sample | 前 70% 数据用于寻优 / 后 30% 数据用于一次性验证 |
| 夏普 / 卡玛 / 索提诺比率 | Sharpe / Calmar / Sortino Ratio | 风险调整后收益指标，公式见 8.2 |
| 最大回撤 | Maximum Drawdown | 权益自历史峰值回落的最大幅度 |

### 11.2 参数速查卡

| 参数 | 默认值 | 优化范围 |
|------|--------|---------|
| `window_minutes`（开盘区间分钟数） | 15 | 10 / 15 / 30 |
| `k1`（上轨系数） | 0.5 | 0.2–0.9，步长 0.1 |
| `k2`（下轨系数） | 0.5 | 0.2–0.9，步长 0.1 |
| `atr_length`（ATR 周期） | 30 | 20–60 |
| `stop_atr_mult`（止损 ATR 倍数） | 2.0 | 1.5–2.5 |
| `fixed_size`（固定手数） | 1 | 1–5 |
| `force_close_time`（强平时间） | 14:55 | 14:50–14:59 |

关键常量：观察期 21:00–21:15（15 根 1 分钟 bar）；轨道 `Upper = RangeHigh + K1 × Range`、`Lower = RangeLow - K2 × Range`；止损 `max(ATR(30) × stop_atr_mult, 0.5 × Range)`；14:55 强平；合约 10 吨/手、最小变动 5 元/吨；手续费 3 元/手双边；保证金率 10%；回测滑点假设 1 tick（50 元/手）；起始资金 10 万。
